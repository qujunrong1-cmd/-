# 无畏契约数据分析：方法论与口径手册

分析结论的可信度取决于三件事：**口径对不对**、**基准有没有样本**、**有没有说清局限**。
任何一条缺失，结论都应该降级为"猜测"。

---

## 1. 指标口径表（最容易出错的地方）

| 指标 | 正确定义 | 常见错误 | 说明 |
|---|---|---|---|
| K/D | 击杀 ÷ 死亡 | 用 KDA 冒充 K/D | App 里的「KDA」多为 (击杀+助攻)÷死亡，会虚高约 40% |
| KAST | 有击杀/助攻/存活/被补枪的回合占比 | 当成「参与率」模糊理解 | 其补集 = 白给率（每局有多少回合纯亏） |
| ADR | 总伤害 ÷ 回合数 | 与「每局伤害」混用 | 只反映输出量，不反映输出效率 |
| 爆头率 HS% | 爆头**击杀** ÷ 总击杀（Riot/第三方口径） | 把「头部命中占比」当爆头率 | 两者分母不同（击杀 vs 命中），**不可直接比** |
| 头/身命中比 | 头部命中次数 ÷ 身体命中次数 | 无 | 不受枪械数量与交战次数干扰，跨玩家可比性最好 |
| 每杀所需命中 | 总命中 ÷ 击杀数 | 无 | 直接等价于"击杀一个人要花多少时间"，是爆头率的价值量化 |
| eDPI | DPI × 游戏内灵敏度 | 只看灵敏度数值 | cm/360 = 13063 ÷ eDPI，这个才是可比的物理量 |
| 首杀率 FB% | 拿到首杀的回合占比 | 用「场均首杀」代替 | 场均首杀受节奏影响，FB% 才是决策质量的度量 |
| ESR 入场成功率 | 赢下的首个交火 ÷ 发起的首个交火 | 用击杀数代替 | 决斗位真正的 KPI，需要分回合数据才能算 |

**掌上无畏契约的问题**：它的「精准击败 xx%」旁边的数字是**部位命中次数**，
三者（头/身/腿）百分比加起来正好 100% —— 这说明它是"命中占比"，不是爆头击杀率。
拿到这类数据时，先做一次加法验算（三项是否约等于 100%），再决定用哪种口径。

## 2. 打分与档位映射

- 每个指标映射到 **0–100 分**：`0 = 黑铁/青铜基线`，`100 = 源能战魂基线`，中间线性插值。
- 越低越好的指标（死亡、每杀命中数）先取反再插值。
- eDPI 用「带型」评分：以 350 为最优点，偏离 150 记 0 分（不是越高越好）。
- **估算档位 = 所有指标的中位分 ÷ 25**（0→黑铁，1→白银/黄金，2→铂金/钻石，3→超凡/神话，4→源能战魂）。

> 为什么用中位而不是均值：单个极端值（例如爆头率极低）会把均值整体拉下来，
> 得出"这是个白银玩家"的错误结论；中位更接近"这个人的常规水平"。

## 3. 可信度判定规则

| 情况 | 处理 |
|---|---|
| 离散度 σ < 15 | 可信度高，可直说档位 |
| 15 ≤ σ < 28 | 可信度中，档位只作参考 |
| σ ≥ 28 | 可信度低：画像两极分化，**必须**改为按短板讨论，不能给单一档位 |
| 可用指标 < 4 项 | 可信度降一级，并列出缺失项 |
| 样本 < 20 局 | 明确标注"样本不足，仅作趋势参考" |
| HS%/部位占比缺失 | 对枪效率相关结论一律标为"待补充数据" |

**原则**：宁可说"数据不足"，不要用一个漂亮数字掩盖不确定性。

## 4. 归因树（症状 → 根因 → 处方）

| 玩家会说的症状 | 数据特征 | 根因 | 处方 |
|---|---|---|---|
| 对枪总输，明明先开枪 | 头/身比低 + 每杀命中数高 | 起始准星在腰线以下，抬枪吃掉 150–250ms | Miyagi 头线法 + 降 eDPI |
| 打腿多 | 腿部命中占比 > 4% | 转角前没画头线 | 三档距离「转身—停准星—开枪」 |
| 数据好但不赢 | ADR 高 + KAST 高 + 胜率低 | 输出发生在非关键回合，用生存换伤害 | 死亡预算 + 换"活下来"的打法 |
| 残局总是差一点 | 死亡数偏高、白给率高 | 血线纪律缺失 | 血量 <50 且无队友 → 退 |
| 每局都在换角色 | 近 10 局 ≥5 个特工 | 没有默认位与角色记忆 | 锁 1 主 1 备，30 局不换 |
| 手感时好时坏 | eDPI 频繁变动 | 没有完成过一次适应周期 | 改一次，锁 30 天 |

同一根因的多个指标（头身比 / 每杀命中数）在报告里**只保留一条**，避免重复开处方。

## 5. 排课原则

1. **热身是固定成本**：`clamp(3, 15%×每日时长, 5)` 分钟，不可省。
2. **时间越少越只练一件事**：15 分钟版砍掉副项，集中攻主项。
3. **副项必须换根因**，否则等于把同一个训练做两遍。
4. **周内要有变化日**：同一个动作连做 5 天会脱敏。
5. **每周一次 Benchmark**：过程指标比段位更早反映变化。
6. **最后一天实战验证**：训练场手感 ≠ 实战手感。
7. **改灵敏度期间锁排位**：迁移期必掉分，且会打断新肌肉记忆。

---

## 6. 分析师不该做的事

- **不要用击杀数判断水平。** 击杀是结果，不是能力；ADR/KAST/首杀率才是过程。
- **不要把 VCT 数据直接套给低分段。** 职业局的结构（5 人协同、道具分层）在白银局不存在，
  出场率只能当"高端局缺什么"的参考，不能当"你该选谁"的依据。
- **不要承诺上分。** 350 万条玩家-对局记录的研究显示，击杀/死亡/伤害/战斗评分
  与"能否升段"的相关性很弱。数据是镜子，不是方向盘。
- **不要把社区基准当官方数据。** Riot 不发布段位分项统计，所有分档表都来自第三方样本，
  有选择偏差，必须在报告里标注来源与样本量。
- **不要在样本不足时给确定性结论。** 单场、10 局内的波动是噪声。

## 7. 数据采集清单

需要玩家提供（掌上无畏契约「能力数据」页 + 战绩页）：

| 界面上的字段 | JSON 字段 | 是否必需 |
|---|---|---|
| 总局数 | `raw.games` | 必需 |
| 击败数 / 死亡数 / 助攻数 | `raw.kills` / `deaths` / `assists` | 必需 |
| 率先击败 | `raw.first_bloods` | 建议 |
| 回合伤害 | `raw.adr` | 必需 |
| KAST | `raw.kast`（小数或百分数都行） | 必需 |
| 命中部位次数（头/身/腿） | `raw.hit_head` / `hit_body` / `hit_leg` | 必需（对枪效率全靠它） |
| 胜率 | `raw.win_rate` | 建议 |
| DPI / 灵敏度 | `raw.dpi` / `raw.sens`（或直接 `raw.edpi`） | 建议 |
| 最近对局的特工与局数 | `agents_recent[]` | 建议（判断角色稳定性） |
| 是否正在改灵敏度 | `constraints.sens_change` | 建议（影响排课） |

缺字段不会报错，引擎会跳过对应指标，但可信度会自动降级。
